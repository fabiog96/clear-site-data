## Privacy Policy - Clear Site Data

Clear Site Data does not collect, store, transmit, or share any personal data.
The only value it stores is the user's notifications on/off preference, saved with Chrome's built-in storage (synced across the user's devices if Chrome sync is enabled).

The extension operates entirely locally within the user's browser.
It only accesses cookies and site data for the purpose of clearing them upon user request.

No data is sent to external servers.
No tracking, analytics, or user profiling is performed.

The extension may display local browser notifications to inform the user when an action is completed.
Notifications can be turned off from the extension icon's right-click menu.
